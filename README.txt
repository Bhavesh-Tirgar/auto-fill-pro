========================================================================
Auto Fill Pro v2.0 - Privacy-First Smart Form Auto-Filler
========================================================================

Auto Fill Pro is a zero-dependency, local-only Chrome Extension engineered
to reliably fill job applications, scholarship portals (including Indian
central/state scholarship systems), campus placement forms, and complex multi-step
web forms.

KEY FEATURES
- 100% On-Device & Zero Telemetry: No external servers, no tracking, no analytics.
- Hard Safety Blacklist: Never stores or touches passwords, OTPs, CVVs, card numbers,
  bank accounts, IFSC, Aadhaar, PAN, or government ID numbers.
- Zero Dangerous Automations: Never ticks checkboxes (terms/declarations) and never clicks submit.
- Non-Destructive: Never overwrites existing form values unless explicitly enabled.
- Smart Matching: Synonym dictionary with fuzzy matching and confidence highlighting.
- Education Disambiguation: Intelligently separates 10th, 12th, Graduation, and Post-Graduation.
- Custom Widgets: Compatible with React-Select, MUI Autocomplete, Select2, and Google Forms.
- Teach This Field: Right-click any custom field to save site-specific mappings.
- Data Security: Optional PIN lock with PBKDF2 + AES-GCM 256-bit encryption.

INSTALLATION (Chrome / Chromium / Edge / Brave)
1. Open chrome://extensions/ (or edge://extensions/).
2. Enable "Developer mode" in the top-right corner.
3. Click "Load unpacked".
4. Select the "auto-fill-pro" folder.
5. Auto Fill Pro is now ready!

KEYBOARD SHORTCUTS
- Ctrl+Shift+F (Mac: Cmd+Shift+F): Quick fill active tab
- Alt+Shift+F: Open extension popup

LICENSING & TIERS
- Free Tier: Up to 2 profiles, standard auto-fill, custom mappings.
- Pro Tier: Unlimited profiles, local resume import, document attachment helper.
